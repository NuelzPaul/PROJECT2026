# PROJECT2026: Roots & Rhythm Christmas Party

Website for the African & Caribbean Society Christmas party (18-24 December 2026).
Built with plain HTML and CSS only.

## Pages
- `intro.html` - home page
- `schedule.html` - day by day schedule
- `activities.html` - music, fashion, stories and football
- `meals.html` - food and dietary requests
- `rsvp.html` - event details and how to RSVP
- `performance-reg.html` - performance registration (Google Form)

## Styles
- `css1.css` - shared styles (colours, text, navigation, buttons, footer)
- `css2.css` - page styles and Christmas decorations (load after css1.css)

## Folders
- `images/` - photos
- `media/` - video and audio on the Activities page

Open `intro.html` in a browser to view the site.
